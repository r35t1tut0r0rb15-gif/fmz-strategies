## Equity-based order size and the entries  [lines 241-244]
  241: ordersize=floor(strategy.equity/close) // To dynamically calculate the order size as the account equity increases or decreases.
  242: strategy.entry("long",strategy.long,ordersize,when=buy) // Buys when buy condition met
  243: strategy.close("long", when = sell ) // Closes position when sell condition met
  244: strategy.entry("short",strategy.short,ordersize,when=sell)
